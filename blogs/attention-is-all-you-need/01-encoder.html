Token Embedding — Scaled

A learned matrix $E \in \mathbb{R}^{|V| \times d}$ maps each token ID to a dense vector — a lookup, not a computation. §3.4 adds a detail often left out of summaries: the embedding is multiplied by $\sqrt{d_{\text{model}}}$ before it's combined with positional encoding, so the embedding's magnitude is on a comparable scale to the sinusoidal signal:

$$x_i = E[\text{token}_i]\cdot\sqrt{d_{\text{model}}} \in \mathbb{R}^{d_{\text{model}}}$$ $$X = [x_1;\, x_2;\, \ldots;\, x_n] \in \mathbb{R}^{n \times d_{\text{model}}}$$
Weight Tying — §3.4 This same matrix $E$ is not unique to the encoder. The paper ties it to the decoder's input embedding and to the decoder's pre-softmax output projection — one shared weight matrix used in three places across the whole model.

Positional Encoding

Self-attention is permutation-equivariant — shuffling input rows shuffles output rows identically. §3.5 injects a unique signal per position $i$ using sinusoids of different frequencies, chosen specifically because "for any fixed offset $k$, $PE_{i+k}$ can be represented as a linear function of $PE_i$" — making relative positions easy for the model to learn to attend to:

$$PE(i,\, 2k) = \sin\!\left(\frac{i}{10000^{2k/d}}\right), \quad PE(i,\, 2k{+}1) = \cos\!\left(\frac{i}{10000^{2k/d}}\right)$$ $$X_{\text{final}} = X + PE \in \mathbb{R}^{n \times d_{\text{model}}}$$

§5.4 additionally applies dropout ($P_{drop}=0.1$) to this sum before it enters layer 1 — the first of many dropout applications throughout the stack.

Critical Distinction Every token embedding $x_i$ is context-free: the vector for "bank" is identical in "river bank" and "bank account." The encoder's sole function is transforming these into context-aware vectors.

step 02

The 6-Layer Stack — Iterated Refinement

Note Layers share structure but not weights. Each layer $\ell$ has its own independent parameter set $\theta_\ell$. §3.1 fixes $N=6$ for the base and big models alike.

The encoder applies $N = 6$ identical-in-structure but independent-in-parameters transformations, each mapping $\mathbb{R}^{n \times d} \to \mathbb{R}^{n \times d}$:

$$Z^{(0)} = X, \qquad Z^{(\ell)} = f_\ell\!\left(Z^{(\ell-1)}\right), \quad \ell = 1\ldots 6$$

Iterated Refinement

Each residual connection casts the encoder as iterative refinement. The representation at layer $\ell$ is the previous plus a learned correction $\delta^{(\ell)}$:

$$Z^{(\ell)} = Z^{(\ell-1)} + \delta^{(\ell)}, \qquad z_i^{(6)} = x_i + \sum_{\ell=1}^{6} \delta_i^{(\ell)}$$

step 03

Inside One Encoder Layer — Two Sub-layers

§3.1: "Each layer has two sub-layers. The first is a multi-head self-attention mechanism, and the second is a simple, position-wise fully connected feed-forward network." Both are wrapped identically:

$$\text{Output} = \text{LayerNorm}(x + \text{Sublayer}(x))$$
Dropout, §5.4 Before each residual addition, $\text{Sublayer}(x)$ has dropout applied to its output: $\text{LayerNorm}(x + \text{Dropout}(\text{Sublayer}(x)))$, $P_{drop}=0.1$ for the base model.
Post-norm — and why it matters if you implement it today The original paper places LayerNorm after the residual add: $\text{LayerNorm}(x + \text{Sublayer}(x))$. This is post-norm. It works here only because of the learning-rate warmup schedule (§5.3) — without warmup, post-norm Transformers are notoriously unstable to train, since early gradients through the un-normalised residual can blow up. Most modern implementations (GPT, ViT, etc.) instead use pre-norm, $x + \text{Sublayer}(\text{LayerNorm}(x))$, which trains stably without warmup. If you reimplement the paper faithfully, keep the warmup; if you drop warmup, switch to pre-norm.
Sub-layer 1 — Multi-Head Self-Attention

Every token attends to every other. $Q$, $K$, $V$ all derived from the same input — hence self-attention. Runs $h = 8$ heads in parallel, each in a $d_k = 64$ subspace.

$H^{(1)} = \text{LayerNorm}(X + \text{MHA}(X,X,X))$
Sub-layer 2 — Position-wise FFN

A two-layer MLP applied independently to each token position. No cross-position mixing. $d_{ff} = 2048$ — a 4× expansion then contraction.

$Z^{(\ell)} = \text{LayerNorm}(H^{(1)} + \text{FFN}(H^{(1)}))$

Residual Connections

Without residuals, gradients must propagate through $6 \times (\text{MHA} + \text{FFN})$ transformations. The identity term guarantees a non-vanishing gradient path:

$$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial H} \cdot \left(I + \frac{\partial F}{\partial x}\right)$$

Layer Normalisation

§3.1: all sub-layers, and the embedding layers, produce outputs of dimension $d_{\text{model}}=512$ to make the residual sum well-defined. LayerNorm normalises across the feature dimension $d$ per token independently:

$$\mu = \frac{1}{d}\sum_j z_j, \quad \sigma^2 = \frac{1}{d}\sum_j (z_j - \mu)^2$$ $$\text{LN}(z) = \gamma \odot \frac{z - \mu}{\sqrt{\sigma^2 + \varepsilon}} + \beta, \quad \gamma,\beta \in \mathbb{R}^d \text{ learned}$$
Full Layer Forward Pass $A = \text{LayerNorm}(Z^{(\ell-1)} + \text{Dropout}(\text{MHA}(Z^{(\ell-1)}, Z^{(\ell-1)}, Z^{(\ell-1)})))$
$Z^{(\ell)} = \text{LayerNorm}(A + \text{Dropout}(\text{FFN}(A)))$
where $\text{FFN}(x) = \max(0,\, xW_1 + b_1)W_2 + b_2$,  $W_1 \in \mathbb{R}^{512\times 2048}$, $W_2 \in \mathbb{R}^{2048\times 512}$

step 04

Attention as a Graph Operation

Graph Theory Encoder self-attention = graph convolution on a fully connected directed graph. Nodes = tokens, edges = $a_{ij}$ weights. Edge weights are data-dependent — the graph rewires per sentence.

Define a fully connected directed graph $G = (V, E)$ where $V = \{1,\ldots,n\}$ are token positions. Attention performs a weighted aggregation:

$$z_i = \sum_{j=1}^{n} a_{ij} \cdot v_j, \qquad a_{ij} \geq 0,\quad \sum_j a_{ij} = 1$$

Geometric Interpretation "bank" starts at the same point in $\mathbb{R}^{512}$ regardless of sentence. After 6 layers it lands at point $A$ in "river bank" and $B$ in "bank account" — same start, same rule, different corrections.

step 05

Multi-Head Attention — 8 Parallel Representation Subspaces

Dimensions — §3.2.2 $d_{\text{model}} = 512$, $h = 8$, $d_k = d_v = d_{\text{model}}/h = 64$. §3.2.1's scaled dot-product attention is run once per head:
$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

The $\sqrt{d_k}$ scaling matters: §3.2.1 notes that for large $d_k$, dot products grow large in magnitude, pushing softmax into regions with extremely small gradients — the scale factor counteracts this. Multi-Head Attention then runs $h = 8$ independent heads in parallel, each learning to focus on a different relational structure; roles emerge from training, not assignment:

$$Q_i = X W^Q_i,\quad K_i = X W^K_i,\quad V_i = X W^V_i \qquad W \in \mathbb{R}^{512\times 64}$$ $$\text{MHA}(X) = \text{Concat}(\text{head}_1,\ldots,\text{head}_8)\,W^O, \quad W^O \in \mathbb{R}^{512\times 512}$$

§3.2.2: "due to the reduced dimension of each head, the total computational cost is similar to that of single-head attention with full dimensionality." Splitting into 8 × 64-dim heads costs about the same as one 512-dim head, while letting the model attend to different representation subspaces simultaneously.

PyTorch Implementation

class EncoderLayer(nn.Module):
    def __init__(self, d_model=512, num_heads=8, d_ff=2048, dropout=0.1):
        super().__init__()
        self.self_attn = MultiHeadAttention(d_model, num_heads)
        self.ffn       = PositionwiseFFN(d_model, d_ff)
        self.norm1     = nn.LayerNorm(d_model)
        self.norm2     = nn.LayerNorm(d_model)
        self.dropout   = nn.Dropout(dropout)

    def forward(self, x, mask=None):
        # Q = K = V = x  →  self-attention
        attn_out = self.self_attn(x, x, x, mask)        # [B, n, 512]
        x = self.norm1(x + self.dropout(attn_out))      # Add & Norm
        ffn_out = self.ffn(x)                           # [B, n, 512]
        x = self.norm2(x + self.dropout(ffn_out))       # Add & Norm
        return x  # [B, n, 512] — shape invariant
