Token Embedding

A learned embedding matrix E ∈ ℝ|V|×d maps each integer token ID to a dense vector. For token index t, the embedding is simply the t-th row of E. This is a lookup — not a computation. The result for a sequence of n tokens is a matrix X ∈ ℝn×d where each row xᵢ ∈ ℝᵈ carries the token's identity but nothing about its context.

x_i = E[token_i] ∈ ℝ^d_model // row lookup
X = [x_1; x_2; ...; x_n] ∈ ℝ^(n × d_model)

Positional Encoding

Self-attention is permutation-equivariant by construction — if you shuffle the input rows, the output rows shuffle identically. The model has no inherent notion of sequence order. Positional encoding injects a unique signal for each position i using sinusoids of different frequencies:

PE(i, 2k) = sin(i / 10000^(2k / d_model))
PE(i, 2k+1) = cos(i / 10000^(2k / d_model))

X_final = X + PE ∈ ℝ^(n × d_model) // elementwise addition

The sinusoidal basis allows the model to attend by relative position via linear transformations, and generalises to sequence lengths unseen during training. The shape remains ℝⁿˣ⁵¹² — the positional encoding adds information without changing the dimensionality.

Every token embedding xᵢ is context-free: the vector for "bank" is identical in "river bank" and "bank account." The entire purpose of the 6-layer encoder stack is to transform these context-free vectors into context-aware vectors by allowing each token to aggregate information from all other tokens. This transformation is the encoder's sole function.

STEP 02
The 6-Layer Stack — Iterated Refinement
Note Layers share structure but NOT weights. Each layer ℓ has its own independent parameter set θ_ℓ. Total encoder parameters ≈ 6 × (per-layer params).

The encoder applies a sequence of N = 6 identical-in-structure but independent-in-parameters transformations. Each layer maps ℝn×d → ℝn×d, making the stack a well-defined composition:

Z^(6) = f_6 ∘ f_5 ∘ ... ∘ f_1(X) // output: context-aware

Iterated Refinement and Fixed Points

Each residual connection casts the encoder as a form of iterative refinement. The representation at layer ℓ is the previous representation plus a learned correction δ⁽ˡ⁾:

Z^(ℓ) = Z^(ℓ-1) + δ^(ℓ) where δ^(ℓ) = Sublayer(Z^(ℓ-1)) - Z^(ℓ-1) (pre-norm view)

Total displacement of token i across all layers:
z_i^(6) = x_i + Σ_{ℓ=1}^{6} δ_i^(ℓ)

The fixed point condition — where further layers produce no correction, δ = 0 — is never enforced explicitly, but the model naturally converges toward it empirically. Early layers produce large corrections (gross structural signal); later layers produce small, precise corrections (fine-grained semantic disambiguation).

STEP 03
Inside One Encoder Layer — Two Sub-layers

Each of the 6 layers applies exactly two sub-layers in sequence, each wrapped in a residual connection and Layer Normalization. Let x denote the input to a given sub-layer:

Output = LayerNorm( x + Sublayer(x) ) // Add & Norm
Sub-layer 1 — Multi-Head Self-Attention

Every token attends to every other token. Query, Key, and Value matrices are all derived from the same input — hence self-attention. Runs h = 8 attention heads in parallel, each operating in a different d_k = 64 dimensional subspace.

H⁽¹⁾ = LayerNorm(X + MHA(X, X, X))
Sub-layer 2 — Position-wise FFN

A two-layer MLP applied independently and identically to each token position. No information mixes across positions here. Inner dimension d_ff = 2048 — a 4× expansion then contraction.

Z⁽ˡ⁾ = LayerNorm(H⁽¹⁾ + FFN(H⁽¹⁾))

Residual Connections — Gradient Analysis

The residual connection is not cosmetic — it fundamentally changes the gradient flow. Without it, gradients must propagate through 6 × (MHA + FFN) transformations, each with potentially near-zero Jacobian. With the residual:

∂L/∂x = ∂L/∂H · (I + ∂F/∂x)

// The identity term I guarantees a non-vanishing gradient path
// even when ∂F/∂x ≈ 0 (dead sub-layer)

Layer Normalisation

LayerNorm normalises across the feature dimension d for each token independently — not across the batch or sequence dimension. Given a vector z ∈ ℝᵈ:

μ = (1/d) Σ_j z_j
σ² = (1/d) Σ_j (z_j - μ)²
LN(z) = γ ⊙ (z - μ) / √(σ² + ε) + β

// γ, β ∈ ℝᵈ are learned affine parameters
// ε ≈ 1e-6 for numerical stability

This is in contrast to BatchNorm, which normalises across the batch dimension per feature — unstable for variable-length sequences and small batch sizes.

A = LayerNorm( Z^(ℓ-1) + MHA(Z^(ℓ-1), Z^(ℓ-1), Z^(ℓ-1)) )
Z^(ℓ) = LayerNorm( A + FFN(A) )

where FFN(x) = max(0, xW₁ + b₁)W₂ + b₂
W₁ ∈ ℝ^(512×2048), W₂ ∈ ℝ^(2048×512)
STEP 04
Attention as a Graph Operation — Computing the Corrections
Graph Theory Encoder = graph convolution on a fully connected directed graph.

Nodes = tokens
Edges = a_ij weights
Edge weights = f(node features) — data-dependent, not fixed

The mechanism that computes each correction δ is attention. Formally, define a fully connected directed graph G = (V, E) where V = {1,...,n} are token positions and each edge (i→j) carries a learned weight aij. The attention operation performs a weighted aggregation over this graph:

z_i = Σ_{j=1}^{n} a_{ij} · v_j

where a_{ij} ≥ 0 and Σ_j a_{ij} = 1 // simplex constraint
Thepos 1
⟺
catpos 2
⟺
satpos 3
Complete directed graph — all 9 edges active (including self-loops) · Edge weight a_ij is data-dependent

Numerical Example

For "sat" attending to "The cat sat" with learned weights:

a_{sat,The} = 0.10, a_{sat,cat} = 0.70, a_{sat,sat} = 0.20
(sum = 1.00 ✓)

z_sat = 0.10·v_The + 0.70·v_cat + 0.20·v_sat

// "sat" is now 70% informed by "cat"
// who-is-doing-the-sitting is encoded in z_sat

Where do a_ij Come From?

The weights are computed via Scaled Dot-Product Attention (§3.2 — next section). The key point here: they are not fixed parameters. They are a function of the input itself — the graph rewires for every sentence. This is what distinguishes Transformer attention from conventional fixed-weight graph convolution.

Each layer repositions every token vector in ℝ⁵¹². The token "bank" starts at the same point in ℝ⁵¹² regardless of sentence. After 6 encoder layers, "bank" in "river bank" has been moved to point A, while "bank" in "bank account" has been moved to point B — via 6 rounds of context-informed corrections accumulated from neighbouring tokens.

Sentence A: z_bank = x_bank + Σ_{ℓ} δ^(ℓ)_{bank | river context}
Sentence B: z_bank = x_bank + Σ_{ℓ} δ^(ℓ)_{bank | account context}
// same start, same update rule, different corrections → different endpoints
STEP 05
Multi-Head Attention — 8 Parallel Representation Subspaces
Dimensions d_model = 512
h = 8 heads
d_k = d_v = 512/8 = 64

Each head projects into a 64-dim subspace — lower dim, but 8 independent views.

A single attention head computes one set of attention weights — one "perspective" on the sequence. Multi-Head Attention runs h = 8 independent attention heads in parallel, each learning to focus on a different type of relational structure (subject-verb, coreference, positional proximity, etc.). No head is explicitly assigned a role — these emerge from training.

For head i (i = 1..8):
Q_i = X · W^Q_i, W^Q_i ∈ ℝ^(512×64)
K_i = X · W^K_i, W^K_i ∈ ℝ^(512×64)
V_i = X · W^V_i, W^V_i ∈ ℝ^(512×64)

head_i = Attention(Q_i, K_i, V_i)

MHA(X) = Concat(head_1, ..., head_8) · W^O
// W^O ∈ ℝ^(512×512) — projects concatenation back to d_model

Why Projection into Subspaces?

Each head operates in a lower-dimensional subspace (ℝ⁶⁴ rather than ℝ⁵¹²). This is not just a computational trick — it forces each head to specialise. A single full-dimensional head would try to capture all relationship types simultaneously with a single query-key dot product. 8 heads in 64-dimensional subspaces can each develop a distinct geometric basis for measuring token similarity.

PyTorch Implementation

class EncoderLayer(nn.Module):
    def __init__(self, d_model=512, num_heads=8, d_ff=2048, dropout=0.1):
        super().__init__()
        # Sub-layer 1: 8 heads, each in d_k=64 dim subspace
        self.self_attn = MultiHeadAttention(d_model, num_heads)
        # Sub-layer 2: pointwise MLP — same weights applied to each position
        self.ffn       = PositionwiseFFN(d_model, d_ff)
        self.norm1     = nn.LayerNorm(d_model)  # γ, β ∈ ℝ^512, learned
        self.norm2     = nn.LayerNorm(d_model)
        self.dropout   = nn.Dropout(dropout)

    def forward(self, x, mask=None):
        # Q = K = V = x  →  self-attention (tokens attend to themselves)
        attn_out = self.self_attn(x, x, x, mask)         # [B, n, 512]
        x = self.norm1(x + self.dropout(attn_out))       # Add & Norm

        ffn_out = self.ffn(x)                            # [B, n, 512]
        x = self.norm2(x + self.dropout(ffn_out))        # Add & Norm

        return x  # [B, n, 512] — shape invariant ✓
STEP 06
Shape Flow and Encoder Output

One of the encoder's defining properties is shape invariance — every transformation preserves the tensor dimensions. This is what enables N identical layers to be composed without any adapter or projection between them.

What the Encoder Output Represents

The matrix Z⁽⁶⁾ ∈ ℝⁿˣ⁵¹² is a continuous manifold embedding of the input sequence. Each row z_i⁽⁶⁾ encodes not just the identity of token i, but its syntactic role, its semantic meaning in this specific context, and its relationships to every other token — accumulated across 6 layers of attention-weighted aggregation and nonlinear transformation.

This output is passed to each of the 6 decoder layers as the Keys and Values in cross-attention. The decoder will query these representations to generate the output sequence — but that is the subject of the next section.

Z⁽⁶⁾ = f_6 ∘ f_5 ∘ f_4 ∘ f_3 ∘ f_2 ∘ f_1(X + PE)

where each f_ℓ(Z) = LayerNorm(A + FFN(A))
and A = LayerNorm(Z + MHA(Z, Z, Z))

f_enc : ℝ^(n × d_model) → ℝ^(n × d_model)
// shape invariant · fully parallel · no recurrence · O(1) path length between any two tokens
