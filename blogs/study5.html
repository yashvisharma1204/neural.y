step 02

Weight Tying — One Matrix, Three Roles

§3.4: "we share the same weight matrix between the two embedding layers and the pre-softmax linear transformation." That single matrix $E$ is used in three places:

1 — Input embedding
Encoder token IDs index rows of $E$ to become 512-dim vectors.
2 — Output embedding
Decoder's shifted target IDs index the same $E$.
3 — Pre-softmax
Decoder output is projected by $E^\top$ to produce logits over the vocab.
$$\text{embed}(t) = E[t], \qquad \text{logits} = D^{(N)}\,E^\top, \qquad P = \text{softmax}(\text{logits})$$
Why tie the weights Input embedding and output projection are conceptually inverse operations — one maps a token to a vector, the other scores a vector against every token. Tying them halves the parameter count of the largest table in the model and couples the two directions, which is known to help generalisation (Press & Wolf, 2017 — the paper §3.4 cites for this). It also assumes a shared source/target vocabulary, as the paper uses.

step 03

The √d_model Scaling

§3.4: "In the embedding layers, we multiply those weights by $\sqrt{d_{\text{model}}}$." Only the two embedding lookups get scaled — not the pre-softmax projection.

$$x = E[t] \cdot \sqrt{d_{\text{model}}} = E[t]\cdot\sqrt{512}$$

Embedding weights are typically initialised with variance $\approx 1/d_{\text{model}}$, so raw lookups have small magnitude. The positional encodings, by contrast, are sinusoids in $[-1, 1]$. Multiplying embeddings by $\sqrt{d_{\text{model}}}$ rescales them so token identity is not drowned out when the positional signal is added on top — the two contributions enter the residual stream at comparable magnitudes.

Scaled here, not at the output The $\sqrt{d_{\text{model}}}$ factor applies to the input and output embeddings only. When the same $E$ is reused as the pre-softmax projection $E^\top$, no scaling is applied there — the softmax temperature is handled implicitly by the learned magnitudes. 
class TiedEmbedding(nn.Module):
    def __init__(self, vocab_size, d_model=512):
        super().__init__()
        self.d_model = d_model
        self.E = nn.Embedding(vocab_size, d_model)   # the one shared matrix

    def embed(self, ids):
        return self.E(ids) * self.d_model ** 0.5      # ×√512

    def project(self, h):                            # pre-softmax, no scaling
        return h @ self.E.weight.T                     # [B, m, |V|]
