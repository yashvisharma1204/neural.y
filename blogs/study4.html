step 01

One MLP, Applied at Every Position

§3.3: "In addition to attention sub-layers, each of the layers in our encoder and decoder contains a fully connected feed-forward network, which is applied to each position separately and identically. This consists of two linear transformations with a ReLU activation in between."

$$\text{FFN}(x) = \max(0,\, xW_1 + b_1)\,W_2 + b_2$$

The key word is position-wise. Attention is where positions talk to each other; the FFN is where each position, on its own, is transformed by the same little network. No token looks at any other token inside the FFN — it is a pure per-vector map, run in parallel across all $m$ positions.

Dimensions — §3.3 "The dimensionality of input and output is $d_{\text{model}} = 512$, and the inner-layer has dimensionality $d_{ff} = 2048$." So $W_1 \in \mathbb{R}^{512\times 2048}$ and $W_2 \in \mathbb{R}^{2048\times 512}$ — a 4× expand, then a 4× contract back to the residual width.

step 02

Why Expand Then Contract

The 4× inner width is not decoration. The ReLU only does something useful if it has room to carve the space into many linear regions — a wider hidden layer means more ReLU "hinges", so the network can approximate richer per-position functions before squeezing back down.

§3.3 gives an alternate reading: "Another way of describing this is as two convolutions with kernel size 1." A 1×1 convolution over the sequence is exactly a linear layer applied independently at each position — which is why "position-wise" and "1×1 conv" describe the same operation.

Where the parameters hide $W_1$ and $W_2$ together hold $512 \times 2048 + 2048 \times 512 \approx 2.1$M weights per layer. Across 6 encoder + 6 decoder layers that is the single largest chunk of the model — the FFNs, not attention, hold most of the Transformer's capacity. §6.2's ablation table backs this up empirically: varying $d_{ff}$ measurably shifts BLEU, confirming the inner width is a real capacity knob, not an arbitrary choice.

step 03

Same Form, Different Weights per Layer

§3.3: "While the linear transformations are the same across different positions, they use different parameters from layer to layer." Two facts packed into one sentence:

Shared across positions
Within a single layer, position 1 and position 40 pass through the exact same $W_1, W_2$. This is what makes it position-wise and lets it run as one batched matmul.
Distinct across layers
Layer 1's FFN and layer 2's FFN have independent weights. Each of the 12 FFNs in the model is its own learned function.

Placement in the Layer

The FFN is always the last sub-layer, wrapped in the same residual + LayerNorm pattern as attention:

$$\text{output} = \text{LayerNorm}\big(x + \text{Dropout}(\text{FFN}(x))\big)$$

PyTorch Implementation

class PositionwiseFFN(nn.Module):
    def __init__(self, d_model=512, d_ff=2048, dropout=0.1):
        super().__init__()
        self.w1 = nn.Linear(d_model, d_ff)     # 512 → 2048
        self.w2 = nn.Linear(d_ff, d_model)     # 2048 → 512
        self.dropout = nn.Dropout(dropout)

    def forward(self, x):                      # x: [B, m, 512]
        # applied identically to every position
        return self.w2(self.dropout(F.relu(self.w1(x))))
        # [B, m, 512] — shape preserved
The division of labour Attention moves information between positions; the FFN processes the information gathered at each position. A Transformer layer is exactly this two-step rhythm — mix, then think — repeated N times.
