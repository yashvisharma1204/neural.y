step 01

Input Representation — The Shifted Target Sequence

§3.1: "the decoder generates an output sequence... one element at a time... at each step the model is auto-regressive, consuming the previously generated symbols as additional input." Training exploits this with teacher forcing — the entire target sequence is fed in at once, shifted right by one position, so the prediction at position $i$ never sees the ground-truth token at position $i$.

Output Embedding — Tied Weights

§3.4: "we share the same weight matrix between the two embedding layers and the pre-softmax linear transformation... In the embedding layers, we multiply those weights by $\sqrt{d_{\text{model}}}$." The decoder does not use a separate embedding table from the encoder — it's the same $E$, scaled the same way:

$$y_i = E[\text{target}_{i-1}]\cdot\sqrt{d_{\text{model}}} \in \mathbb{R}^{d_{\text{model}}}, \qquad y_0 = E[\langle\text{bos}\rangle]\cdot\sqrt{d_{\text{model}}}$$ $$Y = [y_1;\, y_2;\, \ldots;\, y_m] \in \mathbb{R}^{m \times d_{\text{model}}}$$

Positional Encoding

The same fixed sinusoidal scheme from §3.5 is added, giving each decoder position a unique signal, followed by dropout ($P_{drop}=0.1$, §5.4) before entering layer 1:

$$PE(i,\, 2k) = \sin\!\left(\frac{i}{10000^{2k/d}}\right), \quad PE(i,\, 2k{+}1) = \cos\!\left(\frac{i}{10000^{2k/d}}\right)$$ $$Y_{\text{final}} = \text{Dropout}(Y + PE) \in \mathbb{R}^{m \times d_{\text{model}}}$$
Critical Distinction The shift-right is what makes training parallel and inference sequential the same task. At train time all $m$ shifted positions are scored in one forward pass; at inference each position is produced one at a time and fed back in as the next input.

step 02

The 6-Layer Stack — Generation Conditioned on Source

Note Decoder layers have their own independent parameters, distinct from the encoder's — except for the shared embedding/output matrix $E$. §3.1 fixes $N=6$, matching the encoder's depth.

The decoder applies $N = 6$ layers, each mapping $\mathbb{R}^{m\times d} \to \mathbb{R}^{m\times d}$, but — unlike the encoder — every layer also takes the fixed encoder output $Z^{(6)}$ as a second input:

$$D^{(0)} = Y, \qquad D^{(\ell)} = g_\ell\!\left(D^{(\ell-1)},\, Z^{(6)}\right), \quad \ell = 1\ldots 6$$

step 03

Inside One Decoder Layer — Three Sub-layers

§3.1: "In addition to the two sub-layers in each encoder layer, the decoder inserts a third sub-layer, which performs multi-head attention over the output of the encoder stack. Similar to the encoder, we employ residual connections around each of the sub-layers, followed by layer normalization."

$$\text{Output} = \text{LayerNorm}(x + \text{Dropout}(\text{Sublayer}(x)))$$
Sub-layer 1 — Masked Self-Attention

$Q,K,V$ all from the decoder's own sequence so far, but future positions are masked out. A token can only attend to itself and earlier tokens.

$B^{(1)} = \text{LN}(Y + \text{MaskedMHA}(Y,Y,Y))$
Sub-layer 2 — Encoder-Decoder Cross-Attention

$Q$ from the decoder state, $K$ and $V$ from the encoder output $Z^{(6)}$. This is where source information enters the decoder.

$B^{(2)} = \text{LN}(B^{(1)} + \text{MHA}(B^{(1)}, Z^{(6)}, Z^{(6)}))$
Sub-layer 3 — Position-wise FFN

Identical in form to the encoder's FFN — a 4× expand-contract MLP applied independently per position, no cross-position mixing.

$D^{(\ell)} = \text{LN}(B^{(2)} + \text{FFN}(B^{(2)}))$

Why Three, Not Two

The encoder only needs to relate source tokens to each other. The decoder needs to do two distinct kinds of relating — to its own partial output, and to the source — so attention is split into two sub-layers with different $K,V$ origins, each getting its own residual and normalization.

Full Layer Forward Pass $B^{(1)} = \text{LayerNorm}(D^{(\ell-1)} + \text{Dropout}(\text{MaskedMHA}(D^{(\ell-1)}, D^{(\ell-1)}, D^{(\ell-1)})))$
$B^{(2)} = \text{LayerNorm}(B^{(1)} + \text{Dropout}(\text{MHA}(B^{(1)}, Z^{(6)}, Z^{(6)})))$
$D^{(\ell)} = \text{LayerNorm}(B^{(2)} + \text{Dropout}(\text{FFN}(B^{(2)})))$,  $\text{FFN}(x) = \max(0,\, xW_1 + b_1)W_2 + b_2$

step 04

Causal Masking — Attention as a DAG, Not a Complete Graph

§3.2.3 "We need to prevent leftward information flow in the decoder to preserve the auto-regressive property. We implement this inside of scaled dot-product attention by masking out (setting to $-\infty$) all values in the input of the softmax which correspond to illegal connections."

Before the softmax in sub-layer 1, positions $j > i$ are set to $-\infty$ so their attention weight collapses to zero:

$$\text{score}_{ij} = \begin{cases} \dfrac{q_i \cdot k_j}{\sqrt{d_k}} & j \le i \\[6pt] -\infty & j > i \end{cases} \qquad a_{ij} = \text{softmax}_j(\text{score}_{ij})$$

Numerical Example

For target "Le chat" generating position 3 ("chat"), attention can only see <bos> and "Le" — never a hypothetical position 4:

$$a_{3,\langle\text{bos}\rangle} = 0.15,\quad a_{3,\text{Le}} = 0.35,\quad a_{3,\text{chat}} = 0.50,\quad a_{3,j>3} = 0$$
Train vs. Inference Symmetry The mask is what makes teacher-forced training equivalent to the sequential process at inference: even though all $m$ positions are computed in one matrix multiply during training, each position's output is mathematically identical to what it would be if generated one token at a time.

step 05

Cross-Attention — Where Source Meets Target

§3.2.3 — "Encoder-Decoder Attention" "Queries come from the previous decoder layer, and the memory keys and values come from the output of the encoder. This allows every position in the decoder to attend over all positions in the input sequence."

Query comes from $B^{(1)} \in \mathbb{R}^{m\times 512}$ (target length $m$); Key/Value come from $Z^{(6)} \in \mathbb{R}^{n\times 512}$ (source length $n$). $m$ and $n$ need not match — attention weights form an $m\times n$ matrix. $h=8$ heads run in parallel exactly as in self-attention:

$$Q_i = B^{(1)} W^Q_i,\quad K_i = Z^{(6)} W^K_i,\quad V_i = Z^{(6)} W^V_i \qquad W \in \mathbb{R}^{512\times 64}$$ $$\text{CrossMHA} = \text{Concat}(\text{head}_1,\ldots,\text{head}_8)\,W^O, \quad \text{head}_i = \text{softmax}\!\left(\frac{Q_iK_i^\top}{\sqrt{64}}\right)V_i$$

§3.2.3 draws the analogy directly: this mimics the typical encoder-decoder attention mechanisms used in earlier sequence-to-sequence models — the same $Q$-from-target, $K/V$-from-source pattern used in RNN-based attention models like Bahdanau et al., just computed with the same scaled dot-product mechanism as everything else in this model.

PyTorch Implementation

class DecoderLayer(nn.Module):
    def __init__(self, d_model=512, num_heads=8, d_ff=2048, dropout=0.1):
        super().__init__()
        self.self_attn  = MultiHeadAttention(d_model, num_heads)   # masked
        self.cross_attn = MultiHeadAttention(d_model, num_heads)   # unmasked
        self.ffn        = PositionwiseFFN(d_model, d_ff)
        self.norm1      = nn.LayerNorm(d_model)
        self.norm2      = nn.LayerNorm(d_model)
        self.norm3      = nn.LayerNorm(d_model)
        self.dropout    = nn.Dropout(dropout)

    def forward(self, y, enc_out, tgt_mask, src_mask=None):
        # Sub-layer 1: masked self-attention, Q=K=V=y
        a = self.self_attn(y, y, y, tgt_mask)              # [B, m, 512]
        y = self.norm1(y + self.dropout(a))

        # Sub-layer 2: cross-attention, Q=y, K=V=enc_out
        c = self.cross_attn(y, enc_out, enc_out, src_mask)  # [B, m, 512]
        y = self.norm2(y + self.dropout(c))

        # Sub-layer 3: position-wise FFN
        f = self.ffn(y)                                     # [B, m, 512]
        y = self.norm3(y + self.dropout(f))
        return y  # [B, m, 512] — shape invariant

step 06

Shape Flow, Final Projection, and Decoding

Every decoder sub-layer preserves $[m \times 512]$, same as the encoder. The one shape change in the whole model happens after the stack, projecting into vocabulary space using the tied embedding matrix:

Trained With — §5.4 Label smoothing $\epsilon_{ls}=0.1$ is applied here, at the output distribution — nowhere else in the model. §5.4 notes this hurts perplexity but improves accuracy and BLEU score: the model is deliberately trained to be less confident about the correct token.

Inference — Beam Search, Not Greedy

§6.1: the paper decodes with beam search, beam size 4, and a length penalty $\alpha = 0.6$. Beam search keeps the top-4 partial sequences by cumulative log-probability at every step instead of committing to a single best token:

beams = [ ([BOS], 0.0) ]                     # (tokens, log_prob) × 4
for step in range(max_len):
    candidates = []
    for tokens, score in beams:
        d = decoder_stack(embed(tokens), enc_out)
        logp = log_softmax(d[:, -1, :] @ E.T)      # tied weight E
        for tok, lp in top_k(logp, k=4):
            candidates.append((tokens + [tok], score + lp))
    beams = top_k_by_score(candidates, k=4, length_penalty=0.6)
    if all_ended(beams): break
best = beams[0]
Geometric Interpretation Each generation step re-runs the decoder stack over the growing sequence — no hidden state persists between steps the way it would in an RNN. Position $i$'s representation is recomputed from scratch each time, constrained only by the causal mask and cross-attention to the fixed $Z^{(6)}$. In practice, implementations cache previously computed keys/values (KV-cache) so each new beam step costs $O(1)$ additional work rather than $O(m)$.
